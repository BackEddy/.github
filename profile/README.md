## 🇧🇷 Comece por aqui

O Backeddy transforma um **PC velho** (ou um PC com Windows que já fica ligado) num **servidor de backup** para a casa: os Macs fazem backup sozinhos, pela rede, sem HD pendurado no cabo.

1. **Tem Mac?** Baixe o **[Backeddy for Mac](https://github.com/BackEddy/mac/releases/latest)**. Ele mostra se o backup do Mac está em dia, grava o pendrive do servidor e configura tudo para você.
2. **Leia a [explicação completa em português](https://github.com/BackEddy/mac/blob/main/README.pt-BR.md)**: o que é Time Machine, servidor de backup, máquina virtual, quanto espaço precisa e o passo a passo.
3. **Só tem PC com Windows?** O app **Backeddy for Windows** ainda está chegando. Por enquanto, o servidor guarda o backup dos Macs.

> ⚠️ **É uma versão de teste**, feita por uma pessoa com muita ajuda de inteligência artificial. Funciona nos nossos testes, mas: o PC que vira servidor **é apagado por inteiro**; não deixe o Backeddy ser a **única cópia** das suas fotos por enquanto; e o Windows vai **reclamar do instalador** porque ele ainda não tem assinatura digital. [Todos os riscos, explicados](https://github.com/BackEddy/mac/blob/main/README.pt-BR.md#antes-de-come%C3%A7ar-os-riscos). Achou um problema? [Conta pra gente](https://github.com/BackEddy/server/issues).

## 🌎 Start here

Backeddy turns an **old PC** (or a Windows PC that's always on) into a **home backup server**: your Macs back up on their own, over the network. Get **[Backeddy for Mac](https://github.com/BackEddy/mac/releases/latest)** and read the **[plain-English guide](https://github.com/BackEddy/mac#readme)**. ⚠️ Early preview, built with heavy AI assistance: the server PC gets erased, don't make it your only copy yet, and the Windows installer isn't signed yet. [The risks, explained](https://github.com/BackEddy/mac#before-you-start-the-risks).
